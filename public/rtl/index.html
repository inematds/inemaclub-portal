Etapa 1 — Estrategia & Narrativa

Research Agent

Executa 5 pesquisas via Tavily AI SDK: tendencias, concorrentes, audiencia, hooks criativos, topicos virais.

OutputDescricao
research_results.jsonDados estruturados consumidos pelos agentes seguintes
research_brief.mdRelatorio legivel com graficos Mermaid
interactive_report.htmlDashboard interativo com Chart.js

Diretor Criativo

Escolhe UM angulo estrategico. Define direcao visual (mood, cores, fotografia, tipografia). Escreve mensagens-chave por plataforma. Define guardrails.

OutputDescricao
creative/creative_brief.jsonBrief estruturado consumido por Designer, Copywriter, Video
creative/creative_brief.mdBrief legivel exibido na Aprovacao 1

Copywriter (Narrador)

Cria a narrativa central — arco emocional: hook → tensao → solucao → prova → CTA. Headlines, frases-chave, textos para carousel/stories, roteiro de video.

OutputDescricao
copy/narrative.jsonNarrativa estruturada (headlines, key_phrases, emotional_arc)
copy/narrative.mdNarrativa legivel

Etapa 2 — Imagens

Ad Creative Designer

Funcao puramente visual — nao escreve copy. Consome creative_brief.json + narrative.json. Monta HTML + CSS, renderiza PNG via Playwright.

Etapa 3 — Video

Video Quick

Slideshow rapido (10-20s) usando imagens do Designer. 4-6 cenas, transicoes simples, Ken Burns. Render via ffmpeg.

Video Pro

Producao profissional em 4 fases:

FaseO que faz
1. RoteiroScene plan com 30-50 cortes, narracao, musica. Render de rascunho (ffmpeg)
2. ImagensGera imagens reais via API para cada cena unica
3. AprovacaoUsuario revisa roteiro/draft. Timeout 30 min
4. RenderRemotion (default) com fallback para ffmpeg. Timeout 10 min

Notificacoes Telegram do Video Pro

  • [VIDEO_PRO_PROGRESS] plan_ready — roteiro criado
  • [STAGE3_DRAFT_READY] — rascunho renderizado (video enviado ao chat)
  • [VIDEO_PRO_PROGRESS] images_start — gerando imagens
  • [VIDEO_PRO_PROGRESS] render_start — renderizando final
