TRILHA 01 · DIA 1
🧠 Mindset & Método

Pensar como
Vibe Coder

Antes do primeiro `npm install`, existe uma forma de ver o problema. O Vibe Coder não escreve código — ele dirige uma orquestra onde a IA toca todos os instrumentos.

Os 5 princípios do Vibe Coder
🎯
Problema primeiro

Nunca comece pelo código. Comece pela dor do usuário. A IA só é boa se você souber o que pedir.

⚡
Velocidade de aprendizado

O objetivo do MVP não é ter o produto perfeito. É descobrir se você está construindo a coisa certa.

🔄
Ciclos curtos

Nunca passe mais de 2 horas sem rodar o produto. Feedback rápido é o ativo mais valioso.

🧠
Contexto é rei

Quanto mais contexto você der à IA sobre seu produto, mais preciso e consistente o código gerado será.

🚀
Ship early, ship often

Um produto ao vivo com 3 features supera sempre um produto perfeito que nunca saiu do seu computador.

📐
Arquitetura intencional

A IA gera o código, mas quem decide a estrutura é você. Erros de arquitetura no início custam 10x mais tarde.

⚡ Regra de Ouro
Se você não consegue explicar o produto em 2 frases, a IA vai gerar 40 features que ninguém pediu. Antes de abrir o Claude Code, escreva: "Este produto ajuda [quem] a [fazer o quê] para que [resultado]."
CLAUDE.md — Template de Briefing
# Meu SaaS — Briefing para IA ## Produto Plataforma de agentes de IA para times de marketing. Permite criar, orquestrar e monitorar campanhas com IA. ## Stack - Frontend: Next.js 14 + TypeScript + Tailwind - Backend: Node.js + Prisma + PostgreSQL - IA: Claude API + MCP - Auth: NextAuth.js - Billing: Stripe ## Regras - TypeScript estrito, sem any - Componentes pequenos e reutilizáveis - Testes para toda lógica de negócio - Nunca commitar .env

TRILHA 04 · DIA 2
🤖 Agents & MCP

Quando Um Bot
Não Basta

Multi-agentes, orquestração, MCP e memória. O nível onde o SaaS começa a se comportar como um sistema inteligente real.

🧠 Memória dos Agentes
  • Short-term: histórico da conversa atual
  • Long-term: banco de dados (PostgreSQL)
  • Semantic: embeddings (pgvector)
  • Episodic: logs de execuções anteriores
🔌 Skills MCP mais usadas
  • filesystem — leitura/escrita de arquivos
  • browser — scraping e automação web
  • slack — enviar mensagens e notificações
  • github — criar PRs e issues

TRILHA 05 · DIA 3
🤝 Multibots

Plataforma de
Múltiplos Agentes

Arquitetura multi-bot: bots especializados, workspaces isolados e integração com canais externos. O SaaS como plataforma.

Funcionalidades da plataforma
🔑
Workspaces Isolados

Cada cliente tem seu workspace com bots, dados e configurações separadas. Isolamento em nível de DB via tenant_id.

🎛️
Bot Builder

Interface drag-and-drop para configurar system prompts, personalidade, ferramentas MCP e limites de cada bot.

📊
Analytics por Bot

Mensagens, tokens, custo/hora, tempo de resposta médio. Identificar qual bot está mais sobrecarregado.

🔄
Handoff entre Bots

Bot pode transferir conversa para outro especialista. Contexto mantido. O usuário nem percebe a transição.

TRILHA 06 · DIA 3
🚀 Produção

Deploy Real,
Billing & Segurança

O produto vai ao ar. Stripe, landing page que converte, deploy na Vercel e as camadas de segurança que garantem o sono tranquilo.

💳
Stripe Billing

Planos Free/Pro/Enterprise. Webhooks para sync de status. Portal do cliente para gerenciar assinatura sem suporte.

🌐
Landing Page

Hero com CTA claro. Social proof. Tabela de preços. FAQ. Tudo gerado e iterado com Claude Design.

☁️
Vercel + Railway

Frontend na Vercel (edge). Backend e DB no Railway. CI/CD automático via GitHub. Preview deploys em PRs.

🔐
Segurança

Rate limiting por user/IP. Input sanitization. Secrets no Vault. CORS configurado. Logs de auditoria.

📈
Observabilidade

Sentry para erros. Posthog para analytics. Uptime robot para alertas. Logs estruturados com Pino.

⚡
Performance

ISR para páginas estáticas. Redis para cache de respostas frequentes. CDN para assets. Core Web Vitals verde.
