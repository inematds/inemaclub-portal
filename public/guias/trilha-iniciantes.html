Trilha para Iniciantes

Por que essa ordem importa

Os 12 cursos essenciais do INEMA Club, na sequência recomendada — e o motivo de cada um vir onde vem.

A trilha não é uma lista aleatória de cursos bons — é uma progressão. Cada curso entrega uma competência que o próximo assume como pré-requisito: primeiro você aprende a falar com IA, depois a usar as ferramentas certas, depois a entender dados e imagens, depois a construir com agentes de código, e só então a colocar no ar e a arquitetar seu próprio sistema de IA. Pular etapas funciona, mas cria lacunas — cursos mais avançados vão presumir que você já tem a base dos anteriores.

Depois do capstone técnico (INTELECTO), a trilha continua em mais 4 passos: voltar ao Claude Code com profundidade total, transformar esse domínio em um sistema de comando próprio, aprender a vender o que você construiu, e finalmente estruturar tudo isso como um negócio de verdade.

1

FEP — Fundamentos de Engenharia de Prompts

A base de tudo: como falar com a IA

Todo o resto da trilha depende de você saber pedir bem. FEP ensina a estrutura de um prompt eficaz — contexto, instrução, formato, exemplos. Sem isso, qualquer ferramenta de IA (inclusive as que vêm mais na frente, como Claude Code e Codex) entrega resultado abaixo do potencial. É o primeiro curso porque é a interface: todos os outros pressupõem que você já sabe se comunicar com um modelo.

ATIA — Oportunidades Digitais com IA

Prompt bem feito, agora aplicado

Com o vocabulário de prompt em mãos, ATIA mostra a IA em ação: casos de uso reais e onde ela abre oportunidade prática. É a ponte entre "sei escrever um prompt" e "sei onde e como aplicar isso" — evita que o aprendizado fique só na teoria.

3

FDB — Fundamentos de Banco de Dados

De "usar IA" para "construir com IA"

Todo produto de verdade guarda e organiza dados. FDB entrega os fundamentos de desenvolvimento e banco de dados que sustentam qualquer coisa além de um chat — é o curso que prepara o terreno técnico antes de você tocar em ferramentas de código com IA.

4

Vision — Processamento de Imagens com IA

IA não é só texto

Antes de ir para os agentes de código, Vision expande o que "IA" significa: visão computacional e processamento de imagem. Isso importa porque boa parte das ferramentas modernas (inclusive as de código) são multimodais — entender essa camada evita que sua base fique presa só a texto.
